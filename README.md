# 坦克大战（Battle City）

一个用纯 HTML5 Canvas 实现的经典坦克大战游戏，无需任何依赖，打开 `index.html` 即可游玩。

## 玩法

- 控制你的坦克，消灭所有敌方坦克，并**保卫基地（老鹰）**。
- 每关有 20 辆敌方坦克（场上最多同时 4 辆），消灭后进入下一关，敌方速度会逐渐加快。
- 你拥有 3 条命，被击中或基地被毁则游戏结束。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 / J | 开火 |
| 回车 | 开始 / 重新开始 |
| P | 暂停 |
| M | 静音 |

## 地图元素

- 🧱 **砖墙**：可被子弹击毁
- ⬛ **钢墙**：无法被击毁（可阻挡子弹）
- 🌊 **水**：不可通过，但子弹可穿过
- 🌳 **树林**：可通过，且会遮挡坦克
- 🦅 **基地**：被摧毁即游戏结束

## 在线游玩

部署到 GitHub Pages 后，直接访问仓库的 Pages 地址即可。

## 技术说明

- 纯原生 HTML + CSS + JavaScript，单文件 `index.html`。
- 使用 Canvas 绘制，`requestAnimationFrame` 主循环，固定帧率逻辑更新。
- 碰撞检测基于 AABB 与网格地图，子弹采用分段移动防止高速穿墙。
- 音效使用 Web Audio API 实时合成，无需音频资源文件。
